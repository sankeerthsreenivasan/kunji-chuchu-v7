# Kunji ♥ Chuchu — Date Room V7

A mobile-first romantic two-phone Date Room.

## Features
- Room code connection using PeerJS
- Shared actions: hearts, kisses, cake cutting
- Shared chat
- Photo transfer between connected phones
- Synchronized play/pause controls
- Mobile-first romantic UI
